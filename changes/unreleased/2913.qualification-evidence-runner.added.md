- **Added — local candidate qualification runner with trustworthy exit evidence (#2913, `FW-DELIVERY-QUALIFICATION-EVIDENCE-01`):** `bin/qualify-candidate` runs `check-pr-preflight --full` plus the Unit, Integration and Architecture suites (or a `--plan`-substituted table) as `proc_open` children whose stdout/stderr go straight to a log file — no pipes, no shell, no `PIPESTATUS` — and records each component's numeric exit status or terminating signal from `proc_get_status()`, plus PHPUnit counts read from its structured junit file, never inferred from a green log line. HEAD, tree and tracked working-tree state are bound before the run and re-checked after every component and at the end; a dirty tree is refused unless `--allow-dirty` (never a qualification), and any change during the run is `drifted`, also never a qualification. Failure, skipped-test counts, and wrapper/evidence errors stay distinct outcomes; a zero exit contradicted by junit failures/errors, or stale log/junit from a previous run at the same path, is an `evidence_error` with a `reason`, never a pass. A real `SIGINT`/`SIGTERM` terminates still-running children and records them as `signaled` rather than waiting for them to finish. `--only` yields a `partial` receipt; `--jobs=N` runs components concurrently while binding all of them to one head/tree; `SIGINT`/`SIGTERM` (or the `WAASEYAA_QUALIFY_INTERRUPT_AFTER` test seam) write an `interrupted` receipt and exit 130. Every run writes `<out>/receipt.json` atomically; the receipt is written even when refused or when a component's evidence is missing, and is skipped only when the evidence directory or the receipt file itself cannot be written, in which case the runner exits 2 with no success claim on stdout.
