- `make:content-type` now compiles its scaffold into one deterministic artifact plan and publishes it through the shared generation custody instead of writing files and rewriting `composer.json` itself. The command surface, generated entity and provider, Indigenous-orthography support, no-overwrite refusal and next-step output are unchanged, and the provider registration now travels in the plan, so an application's own `composer.json` bytes and formatting survive the merge. Two behaviours change: the scaffold is a seeded unit that is published exactly once and then owned by the developer, so `--force` no longer overwrites an edited scaffold; and publication requires an initialized site, because unit ownership is recorded in `.waaseyaa/generated.json` — scaffolding before `site:init` is now refused instead of writing ungoverned files.
