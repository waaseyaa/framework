  code.** `docs/upgrade-notes/oidc-secrets-at-rest.md` described only the

  `WAASEYAA_APP_SECRET`; it now distinguishes that legacy custody path from the

  describes the normalize-not-just-encrypt resealing behaviour of
  `Security\LegacyOidcSecretMigrator` (opens and reseals legacy rows,

  skips rows already current, and applies every update under a compare-and-set

  `waaseyaa/oidc` sits in `require-dev` and is split-published instead.
