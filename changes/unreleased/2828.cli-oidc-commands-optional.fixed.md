- **Fixed — `oidc:*` commands are no longer registered without `waaseyaa/oidc` (#2828):** a production consumer that installs `waaseyaa/cli` without the suggested `waaseyaa/oidc` package previously listed all seven `oidc:*` operator commands and failed inside their handlers. `OidcServiceProvider` now declares the package through `RequiresOptionalPackagesInterface` (introduced by #2826 for `ai:*`), so package discovery, `list`/`help`, and invocation agree: zero `oidc:*` commands without the package, all seven with it. Core lifecycle commands are unaffected, and `waaseyaa/cli` still does not require `waaseyaa/oidc`.
