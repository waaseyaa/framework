- **Fixed — scaffold:auth resolves auth UI sources from the loaded CLI package sibling without waaseyaa/framework (#2833):** `AuthUiScaffoldManager` only searched the application root and an installed framework metapackage, so ADR-004 direct-package consumers failed `scaffold:auth --check` even when path-installed `waaseyaa/cli` still sat beside `packages/admin/app`. Source lookup now also follows the loaded CLI package (and its realpath'd Composer install path) to that sibling admin app, preserving in-tree and metapackage consumers. No application workaround or metapackage reintroduction.
