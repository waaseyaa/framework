- **Fixed — scaffold:auth resolves auth UI sources from the installed waaseyaa/cli package without waaseyaa/framework (#2833):** `AuthUiScaffoldManager` only searched the application root and an installed framework metapackage, so ADR-004 direct-package consumers failed `scaffold:auth --check` even with `waaseyaa/cli` installed. The five publishable auth UI files now also ship as a generated, byte-identical mirror inside the `waaseyaa/cli` package itself (`resources/auth-ui`, regenerated by `bin/sync-cli-auth-ui-resources` and checked by `CliAuthUiResourceParityTest`), with a loaded-package-local fallback for runtimes Composer does not register. In-tree and metapackage consumers are unchanged. Proven end-to-end against real installed package bytes by `tests/PackagedForm/check-cli-auth-scaffold`, including missing- and corrupted-resource negatives and hand-edit preservation.
