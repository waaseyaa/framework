- **Fixed — MCP no longer advertises a 10 MiB request cap the kernel refuses at 1 MiB (#2637):** `StreamableHttpTransportGuard::DEFAULT_MAX_REQUEST_BYTES` now matches `BodySizeLimitMiddleware` (1,048,576). `McpServiceProvider` fails closed when `mcp.transport.max_request_bytes` exceeds an enabled `http_security.body_size_limit.max_bytes`, so raising the MCP knob cannot advertise an unreachable ceiling. Disabling the kernel control still lets the transport cap stand. Both `docs/specs/security-defaults.md` and `docs/specs/mcp-endpoint.md` record the interaction.
