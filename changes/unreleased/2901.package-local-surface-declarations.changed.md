- **Changed — public-surface disposition moves to package-local declarations (#2901, ADR: `docs/specs/public-surface-declarations.md`):** `docs/public-surface-map.php` and `docs/public-surface-map.md` are now **generated views**, composed by `bin/generate-surface-map` from `packages/<pkg>/public-surface.php` — the single editable authority for an element's `public`/`internal` disposition. Independent packages no longer collide on one shared aggregate: each declares its own contract shapes, and `Waaseyaa\Tooling\SurfaceDeclarations` fails closed on a missing declaration, a duplicate within one file, a declaration outside its owning package's PSR-4 prefix ("orphaned"), or the same FQCN declared by two packages ("contradictory") — one declaration plane means one declaration. `tools/check-surface-parity.php` keeps its path, `--base=<ref>` argument, and exit codes, and now composes both the merge base's and HEAD's declarations before applying the unchanged `SurfaceChangeAuthorization` removal/rename/downgrade rules; it also accepts a tracked aggregate only when it is byte-identical to the merge base's bytes or to a fresh generation from HEAD's declarations, so a PR is never required to hand-commit the regenerated aggregate — the governed release cut does that, exactly as it compiles `CHANGELOG.md`. Every one of the 719 pre-migration dispositions (640 `public`, 79 `internal`, across 53 owning packages) is preserved verbatim by `bin/migrate-surface-map` (kept for provenance); the 33 documentation rows that named no governed FQCN carry over as package `notes`, which govern nothing and broaden nothing. See `docs/specs/public-surface-declarations.md` for the full contract and migration guide, and `docs/specs/stability-charter.md` §2.5/§8.1 for the updated charter authority.
