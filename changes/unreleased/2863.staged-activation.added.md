- **Added — ADR-025 authorizes a staged activation model for #2846's step 1 (#2863, ADR-025 D-12.1, D-12.2):** D-12 step 1 mandated that the transactional artifact-plan engine land as one slice, and a ~2500-line diff across the transaction authority is not reviewably tractable against a serialized reviewer — a defect a reviewer cannot see costs more than a review cycle. A history note cannot override an accepted decision, so the decomposition is recorded in the ADR itself. D-12.1 authorizes eight independently reviewable PRs under three binding constraints: every intermediate PR **leaves incomplete public behaviour unreachable** (no partially-wired type constructible from a handler, no `GEN0xx` emitted by a path that cannot honour it), **preserves existing behaviour exactly** (generated bytes, refusal messages, exit statuses and `site:doctor` output byte-identical at every intermediate commit), and exactly one slice — the last — is named as activating. Each of step 1's five stated reasons for the mandate is answered with a named substitute rather than a general assurance: the byte-identity fixture still lands before the D-2.6 relocation and is now merged four slices ahead of it; the receipt binding still ships with `ArtifactApplyResult`; no `make:*`/`scaffold:*` migration moves into step 1; and #2787 stays blocked on step 1 as a whole rather than on any individual slice. **D-2.7's `site:doctor` same-slice requirement is retained, not relaxed** — D-12.2 records why separating it would need a third mechanism to keep doctor quiet in the intermediate window, which would be a parallel authority for exactly the state it exists to police, so slice 5 carries both the unit model and the doctor split and is large as a deliberate consequence. The model's own failure mode is stated rather than discovered: seven individually correct slices can still compose badly with no user exercising them, so the activation slice carries an end-to-end proof that a publish through the new path produces bytes identical to the old for an unchanged input.
