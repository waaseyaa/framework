- **`waaseyaa/database-legacy` no longer describes itself as wrapping Drupal.**
  Its `composer.json` `description` — the text packagist.org renders for the
  package — read "Database adapter wrapping Drupal DBAL. Interim until Doctrine
  migration." The package requires `doctrine/dbal ^4.0` and contains no Drupal
  code, and ADR-007 ruled the `-legacy` suffix historical extraction lineage
  rather than a deprecation signal, calling the package the supported
  DBAL-backed persistence seam. Both halves of the sentence were therefore
  wrong, on the one surface a prospective consumer reads first, for a package
  39 of 77 first-party packages depend on. The description and the matching
  stale clause in `packages/database-legacy/README.md` now state what the
  package is and cite ADR-007 for the name. Metadata only: no code, constraint,
  autoload or behaviour change, and no rename — ADR-007 decided that and is not
  reopened here.
