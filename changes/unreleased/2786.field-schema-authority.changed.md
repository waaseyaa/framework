- **Changed — entity and blueprint introspection now converge on the registered
  field-type authority (#2786).** `FieldSchemaAuthority` emits closed,
  field-aware entity schemas; API and AI adapters consume it instead of owning
  structural type tables; unregistered field types fail closed; blueprint
  admission is derived from live plugin metadata; and AI schema generation now
  requires an explicit subject, access handler, and account so protected field
  metadata is not exposed by an unscoped catalogue. GraphQL now declares
  scalar `text_long` values as `String`, matching its sanitized resolver output,
  explicitly encodes storage-decoded JSON values for its string adapter, and
  preserves lossless decimals as strings instead of binary floats.
  Field registration now rejects declarations that the live plugin registry
  cannot project, and entity, translation, revision, and SQL-column schema
  builders consume plugin-owned column shapes instead of parallel fallback
  maps. Internal-field visibility is shared across API and AI adapters;
  multi-value enum options are emitted and rendered through `items`; and the
  accepted Admin distribution carries the corrected widget behavior.
