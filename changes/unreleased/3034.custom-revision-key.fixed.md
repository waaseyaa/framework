- **Fixed — configured revision keys in entity base rows (#3034):** `EntityRepository` now honors an entity type's `keys.revision` value for base-row pointers while keeping the internal revision-history column named `revision_id`. SQL-column entities using a custom key such as `vid` can save, load, move, publish, roll back, prune, and backfill revisions without addressing a nonexistent base `revision_id` column.
