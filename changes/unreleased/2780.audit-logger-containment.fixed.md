- **Fixed — a broken audit logger could no longer escape `AuditedToolDispatcher::dispatch()` (#2780):** `finalizeQuietly()` correctly caught a durable-ledger finalization failure after the delegated tool had already run, but the catch then called the injected logger unguarded — a `critical()` throw escaped `dispatch()` after the side effect had already committed, so a caller could receive an exception instead of the completed `ToolDispatchOutcome` and retry an action that already happened. The two other post-decision logging sites in the same class (`agent_tool.audit_reservation_failed`, `agent_tool.audit_terminal_record_failed`) had the identical gap: each reports a refusal that is otherwise final, so a logger throw there would replace an already-decided refusal with an unrelated crash. All three now go through a new private `reportAuditFailure()` helper that wraps the logger call in `try`/`catch (\Throwable)` and swallows silently — a logging failure must never change a caller-visible dispatch outcome, and is deliberately not re-logged (no recursion into a broken sink; `error_log()` is reserved for the logging infrastructure itself).
