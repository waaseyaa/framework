- **`Waaseyaa\CLI\Io\StdinSource` is now reachable from a packaged consumer.**
  `packages/cli/public-surface.php` declares the interface `public`, but it lived
  at `packages/cli/tests/Io/StdinSource.php` and was mapped only by the monorepo
  root's `autoload-dev`. Composer honours `autoload-dev` for the root package
  alone — never for a package installed as a dependency, `require-dev`
  included — so a consumer of the split `waaseyaa/cli` could not autoload it.
  The file moves to `packages/cli/src/Io/StdinSource.php`, which the package's
  existing production mapping (`Waaseyaa\CLI\ => src/`) already covers, so the
  FQCN, the `readLine(): ?string` / `isInteractive(): bool` method set and the
  `public` declaration are all unchanged; no manifest mapping was added. The
  now-stale root `autoload-dev` entry `Waaseyaa\CLI\Io\ => packages/cli/tests/Io/`
  is removed so it cannot shadow the production mapping. New packaged-form proof
  `tests/PackagedForm/check-cli-io-consumer-contract` builds a consumer from the
  exact candidate with path repositories at `symlink=false` and no root-level
  namespace mapping, has it implement the interface and call both methods through
  a `StdinSource`-typed parameter under PHPUnit (including a deliberately
  non-conforming implementation that must be rejected with `TypeError`), then
  repeats the install with `--no-dev` to assert production reachability and a
  clean console-kernel boot. Refs #2961. The conformance-helper scope of #2961
  (`Migration\Testing\*`, `Entity\Testing\Translation\*`) is unchanged and
  remains open.
