- A reviewed artifact apply request can now be decoded by the contract that defines it and executed in a later process: `ArtifactApplyRequest::fromArray()` and `fromCanonicalJson()` fail closed on unknown, missing, duplicate or wrong-typed members, on an invalid nested plan, and on bytes that are not the canonical serialization of the document they decode to, and the new boot-free `site:apply --request=PATH` command publishes exactly those bytes through the existing execution authority without recompiling them. Digest verification is unchanged: the reviewed plan and project-state digests remain the execution authority's `GEN005` check under its lock.
