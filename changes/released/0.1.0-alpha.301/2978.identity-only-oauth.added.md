- **Added — identity-only OAuth configuration for Google and GitHub (#2978, `FW-IDENTITY-ONLY-OAUTH-01`):** `GoogleOAuthProvider` gains optional trailing constructor parameters `accessType: GoogleAccessType` (new backed enum, default `Offline`) and `forceConsent: bool` (default `true`) so a consumer can request Google's online access type without a forced consent prompt; the default 4-argument construction keeps producing the historical `access_type=offline&prompt=consent` authorization URL byte-for-byte, and `refreshToken()` is unchanged for offline consumers. `GitHubOAuthProvider` gains an optional trailing `fetchEmail: bool` (default `true`) so an identity-only consumer can skip the secondary `GET /user/emails` request entirely — only `GET /user` is called, returning a profile with the stable numeric `providerId` and an empty/unverified email — while default construction is unchanged. Both providers' existing fail-loud refusal on a failed or unidentifiable response is untouched. Both providers' optional `email`/`name` extraction is hardened: a missing, `null`, or non-string value (and, for GitHub, a missing/malformed `login` fallback) now degrades to an empty string instead of triggering an "Undefined array key" or "Array to string conversion" PHP warning — the stable `providerId`/id check is unaffected and still refuses a failed or unidentifiable response. See `docs/specs/oauth-provider.md` (new canonical spec) for the full contract and Studio selection example.
