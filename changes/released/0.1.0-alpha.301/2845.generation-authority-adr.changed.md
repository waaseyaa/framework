- **Changed — ADR-025 names the single generation authority and decides how its generated state is partitioned (#2845):** the CLI's twenty-plus `make:*`/`scaffold:*`/`fixture:*`/`site:init` generation entrypoints were built without one authority for transactional safety, `make:content-type` mutates `composer.json` directly with no lock, collision check, or rollback, and the incumbent authority could not express an incremental scaffold at all — `SiteInitializationService::prepare()` compares the whole artifact set unconditionally and refuses on any inequality, so a scaffold could neither add files to an initialized site nor survive the next `site:init`. `docs/adr/025-unified-artifact-generation-authority.md`, with its command inventory at `docs/adr/data/025-generation-command-inventory.json`, decides that `Waaseyaa\CLI\Site\SiteInitializationService` is the single transactional execution authority and `.waaseyaa/generated.json` is the single generated-state authority for every generator — human scaffold, `site:init` preset, or approved blueprint alike. That one document is now partitioned into **generation units** (D-2): an optional `units` roster plus an optional per-row `unit` owner, still `waaseyaa.generated` version 1, with the root `site` unit staying the existing top-level triple so a units-free document is read unchanged and blueprint-free output stays byte-identical per ADR-023. Each unit's path set is frozen exactly as the whole set is frozen today, units the publish did not supply are carried forward untouched, ownership is an exclusive partition where the first recorded owner wins, and a `seeded` disposition lets a one-shot scaffold be edited without ever refusing regeneration. The plan contract is split (D-6) into an immutable `ArtifactPlan` that observes no project, an `EvaluatedArtifactPlan` carrying per-path status against a captured `ProjectStateIdentity`, and an `ArtifactApplyRequest` that carries the reviewed plan itself — with a stated canonical digest formula binding both, so `GEN005_STALE_PLAN` refuses any apply whose plan or project state is not the one that was reviewed. Provenance is recorded per generation unit, not per artifact (D-10.1), and the earlier claim that `site:doctor` can always distinguish a hand scaffold from a blueprint materialization after publication is withdrawn as false (D-10.3). #2664, #2846, and #2787 each compose this authority rather than build a competing one, and #2442's presets are a parallel lane with no #2846 dependency (D-12). This is a decision record only: no generator, handler, or command behavior changes; migration of the five `merge`-disposition commands is sequenced as follow-on issues.
