- Negotiate the search capability before `make:search-projection` writes anything: the handler resolves the search symbols its generated code references and refuses with a stable diagnostic naming the first missing one, leaving the application unchanged. Add a `search:reindex` proof that the generated projector is discovered and executed against a registered entity type, asserting against the stored rows of a real FTS5 index that deliberately-public content is indexed while `Internal` and `Protected` fields never enter the index file. Field-visibility guidance now requires a per-field decision — declare `read: FieldReadLevel::Public` for content meant to be searchable, or leave the field restricted and stop indexing it — and states that widening a field merely to silence the omission is the wrong repair; the restricted default is unchanged.
