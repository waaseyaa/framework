- **Added — `site:init --preset=minimal|editorial` (#2442, ADR-024):** the governed `site:init` experience gains two deterministic, init-time-only presets that land the **declarative half** of a fresh site. `minimal` activates only the `published_content` capability/recipe; `editorial` additionally activates the existing `governed_authoring` recipe, so its capability state, recipe digest, and generated artifacts are published and reviewable in version control. **`editorial` does not by itself reach a running authenticated authoring surface**: the canonical `create-project` -> `site:init` -> `install:init` lifecycle never reruns Composer after generation, and provider discovery reads the literal root `composer.json` rather than the merged result, so a recipe-declared provider and its package requirements are generated but never activated. That gap is **pre-existing** — it affects any manifest that activates `governed_authoring`, preset or not — and is tracked by #2857; its real fix belongs to the materialization contract #2845/#2846 are deciding, not to this change. What lands here is the declaration, the artifacts, and the determinism around them. Both presets start from the same published skeleton and package cohort, neither publishes backend auth/security implementation code of its own, and neither selects the `subscription` capability -- personal-data collection remains a separate, explicit decision. Per ADR-024 D-3/D-4 a preset is resolved once, by `SitePresetResolver`, into an ordinary `waaseyaa.site` answer document before the unchanged `SiteManifestParser` -> `SiteArtifactRendererFactory` -> `SiteInitializationService` pipeline runs; no preset name or runtime profile flag is ever persisted in `.waaseyaa/site.yaml` or `.waaseyaa/generated.json`, and no second transaction, execution, or ownership authority is introduced. `--preset` works both interactively (fewer product questions than the full wizard) and non-interactively. Re-running with the same preset and seed is byte-identical and reports the exact proposed diff, through the existing dry-run/collision/journal machinery.
