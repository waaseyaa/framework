- Add a registered-runtime regression for generated search projections. The projector is compiled from the shipped scaffold compiler rather than hand-copied, and is exercised against a registered entity type whose fields span the classification space: an explicitly `FieldReadLevel::Public` field reaches the search document, while an undeclared field (registered default `Internal`) and a `Protected` field with no granting policy are excluded — at index time with no account scope, and at query time through `EntitySearchCandidateResolver` driving the real `EntityAccessHandler` and `AccountFieldReadScope`. Entity-level denial drops the candidate before any projection is released.
