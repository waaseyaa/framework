- **Changed — the application skeleton is minimal and bootable, with no placeholder directories (#2438, ADR-024):** `composer create-project waaseyaa/waaseyaa` no longer ships fourteen `.gitkeep` placeholders (`src/{Access,Controller,Domain,Entity,Ingestion,Provider,Search,Seed,Support}/`, `storage/`, `files/`, `tests/{,Integration,Unit}/`); eleven of those directories held nothing else and are gone entirely, while `src/Provider/`, `tests/` and `tests/Unit/` already held real files and simply lose the redundant marker. Every optional architectural area now appears only when a deterministic generator writes a real file into it -- `make:content-type` already created `src/Entity/` on demand and writes its provider into the `src/Provider/` that ships with `AppServiceProvider.php`, and `db:init` / the media file repository already created `storage/` and `storage/files` on demand, so no generator behavior changed. `skeleton/phpunit.xml.dist` drops the `Integration` testsuite entry, which pointed at a directory that no longer ships (PHPUnit 13 refuses to boot at all with a declared testsuite directory missing); add it back once you create `tests/Integration/`. Existing applications generated under the previous skeleton are not migrated, and no upgrade path treats the smaller layout as drift.
