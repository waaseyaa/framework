- **Fixed — manifest cache custody (#2788, FW-SITE-BLUEPRINT-01E final follow-up review):** `PackageManifestCompiler::load()` now trusts `storage/framework/packages.php` only when it carries a string `_manifest_inputs_fp` that exactly equals the computed inputs digest; a missing or non-string fingerprint is treated as stale and recompiles. This closes the gap where the byte-identical cached-root permission re-merge exemption could be reached from a legacy or hand-written cache: such a cache holding a package-owned permission that the root application also declares now recompiles through the fail-closed admission and is refused as a package/root `PermissionManifestCollisionException`, never read back as unchanged root ownership. Valid matching-fingerprint cache reuse (no rewrite) and unchanged-root idempotency are preserved and pinned. The scalar root-catalogue regression now supplies a true scalar and asserts the object-shape refusal; list and integer-key coverage stays in the data-provided cases.
