- **Fixed — agent-contract.md and CLAUDE.md now describe a `spec-reviewed:` trailer the drift detector accepts (#2675):** the contract previously implied the trailer was a fallback for every change set that left a spec unchanged, but `tools/drift-detector.sh` discards both a prose-only reason and an acknowledgement naming a spec outside the affected set. The docs now state the two conforming cases explicitly — no affected specs takes no trailer, and an affected spec intentionally left unchanged takes `spec-reviewed: docs/specs/<name>.md - <reason>` naming the exact path.
