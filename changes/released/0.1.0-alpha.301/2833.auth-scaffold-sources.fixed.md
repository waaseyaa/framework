- **Fixed — scaffold:auth resolves auth UI sources from symlinked path-installed `waaseyaa/cli` without waaseyaa/framework (#2833):** `AuthUiScaffoldManager` only searched the application root and an installed framework metapackage, so ADR-004 direct-package consumers failed `scaffold:auth --check` even when Composer path-installed `waaseyaa/cli` still sat beside `packages/admin/app`. Source lookup now also follows the loaded CLI package class location and its realpath'd Composer install path to that sibling admin app, with CLI `InstalledVersions` pretty-version fallback when no `VERSION` file is present. Supported proof profile: symlinked monorepo package path installs without `waaseyaa/framework`. In-tree and metapackage consumers are unchanged. No application workaround or metapackage reintroduction.
