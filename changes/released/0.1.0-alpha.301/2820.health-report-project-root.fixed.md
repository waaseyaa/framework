- **`health:report` runs in a consumer application without an application-local
  binding (#2820).** In a normal consumer (`composer require waaseyaa/core`,
  no application-local container bindings or handler subclasses) the command
  crashed with `Cannot auto-wire "Waaseyaa\CLI\Handler\HealthReportHandler":
  unresolvable parameter "$projectRoot"`. Two defects stacked:
  `HealthSchemaServiceProvider` published the command but never bound the
  handler, and the kernel-owned `HealthCheckerInterface` the handler depends on
  existed only as a handler-container kernel binding — it was not served by the
  kernel-services bus, so even a provider binding could not compose the handler:
  its factory threw `No binding registered for HealthCheckerInterface`, which
  `KernelHandlerContainer` reads as "unbound id", and resolution fell through to
  reflection auto-wiring, which cannot supply a plain `string $projectRoot`.

  `HealthSchemaServiceProvider` now binds `HealthReportHandler` as a singleton
  (project root from `ServiceProvider::$projectRoot`); `AbstractKernel` composes
  one memoized `healthChecker()` that backs both the handler-container kernel
  binding and a new lazy accessor on `ProviderRegistryKernelServices`, so the
  bus serves `HealthCheckerInterface` to providers (documented in
  `docs/specs/infrastructure.md`). When auto-wiring fails after a provider
  factory failed on a dependency, `KernelHandlerContainer` now chains that
  failure and names it, so the true cause is no longer masked.

  Proofs: `tests/Integration/OperatorDiagnostics/HealthReportCommandWiringTest.php`
  composes and executes the command over the real bus in-tree, and the new
  hosted lane `ci/cli-health-report` (`tests/PackagedForm/check-cli-health-report`)
  builds a disposable `--no-dev` `waaseyaa/core` + `waaseyaa/cli` consumer with
  no application source from the candidate tree and executes `health:report`,
  `health:report --json`, and `health:report --json --output` from installed
  bytes. The first proof alone — a unit test over a fake bus — passed against
  the still-broken wiring; the consumer lane is what caught it.
