- Add `make:search-projection`, which scaffolds an application-owned search projector, its `ProvidesEntitySearchProjectorsInterface` provider binding and a companion test through the shared generation custody rather than writing files itself. The unit is seeded and its path set frozen, the provider registration travels in the plan as a `composer.json` merge instruction, and the plan declares its generated test in `companion_tests`. Because the container resolves one search-projector provider, a second scaffold is refused with a diagnostic naming the existing provider instead of silently shadowing it. Generated projectors read every field through the guarded accessor, so index-time projection releases only `FieldReadLevel::Public` fields; the command reports that requirement and the generated test fails loudly when an indexed field is left undeclared.
