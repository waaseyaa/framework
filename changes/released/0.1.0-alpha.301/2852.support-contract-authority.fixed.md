The gate accepts `--root=DIR` and `--contract=PATH` (the `bin/check-s1-sqlite-contract` idiom) and gains fixture-driven negative tests in `tests/Architecture/CheckSupportContractGateTest.php`. Every declared support-reducing transition — including `platform.node.maintenance_start`, which was date-validated and then dropped from the notice set (#2862) — now goes through one shared notice-window computation; a window entered before the next scheduled review requires an explicit `transition_acknowledgements` entry with a pre-transition review date instead of passing silently, and a passed end-of-support date fails closed. The contract records the #2862 acknowledgement for Node 24 maintenance (2026-10-20, review by 2026-10-15) and Composer's relative `support_model` with `dated_eol: false`, so the absence of Composer dates reads as recorded fact.
