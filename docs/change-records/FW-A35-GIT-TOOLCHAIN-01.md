# FW-A35-GIT-TOOLCHAIN-01: remove the vulnerable Admin Git-wrapper chain

Observed October 30, 2026 (Toronto). Base:
`9ce0c9d2033b35eaa69de4d2d205623096ff7f84`.
Forge mirror: [#3243](https://github.com/waaseyaa/framework/issues/3243).

## Scope and invariant

Address only A35's remaining critical Git-toolchain findings:
`simple-git` GHSA-x6jw-m9v5-85vh and `@simple-git/argv-parser`
GHSA-v5rq-49vh-5v5c. The Admin dependency graph must no longer install either
wrapper, including nested or aliased copies. Preserve Nuxt 4.5.2, ordinary
development/DevTools use and the PHP-served static Admin. No forced override,
Nuxt major migration, unrelated advisory cleanup or runtime PHP change.

The locked chain is Nuxt 4.5.2 -> DevTools 3.4.1 -> simple-git 3.36.0 ->
argv-parser 1.1.1. The advisories concern untrusted Git trailer configuration
and unsafe editor environment classification. The installed affected libraries
are confirmed. Current DevTools callers only request branch, short revision and
status; no application route carrying attacker-controlled configuration/env to
the advisory sinks was demonstrated. Absence of that exploit proof does not
remove the vulnerable installed dependency finding.

## Supported owner repair

Fresh npm metadata and the published upstream package confirm DevTools 3.4.4
does not depend on either Git wrapper. Nuxt 4.5.2 declares DevTools `^3.4.1`,
so this patch release fits the actual owner range. This corrects the previous
A35 conclusion that only a DevTools major/removal decision could fix the chain.
Preserve the earlier frozen evidence and its observation; this record owns the
new disposition. Do not force simple-git 4 or parser 2 under their old owners.

Sources: [DevTools manifest](https://registry.npmjs.org/@nuxt/devtools/3.4.4),
[Nuxt manifest](https://registry.npmjs.org/nuxt/4.5.2),

trailer configuration; unsafe editor configuration was refused as a control.

`GIT_EDITOR`. Both affected modules are unresolvable from the candidate's fresh
install and absent from every locked path/edge, so those removed APIs cannot
reproduce their original guard bypasses. No remotely exploitable application

preserves clean, dirty, detached-HEAD and outside-Git fallback behavior. Nuxt
4.5.2 boots with DevTools 3.4.4; the Admin page, actual DevTools client HTML and
its module asset serve successfully. This is HTTP smoke, not a rendered browser
claim. Typecheck, contract compatibility and five focused tooling tests pass;
the new two-test dependency boundary fails on the base and passes after repair.
