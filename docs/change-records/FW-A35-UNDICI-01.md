[cache isolation](https://github.com/advisories/GHSA-vp8m-p9jh-q5pm).

Nuxt's proxy-environment dispatcher imports Agent and EnvHttpProxyAgent.
The library must retain custom TLS identity checks, including direct/NO_PROXY
and BalancedPool alternate option forms, while ordinary trusted TLS, HTTP and
explicit proxy/no-proxy traffic keep working. The Admin is a PHP-served static
SPA; no remote application exploit path is established by these library probes.

The isolated baseline accepts a loopback certificate despite a custom identity
callback rejecting it: Agent tls, Env direct/no-proxy, BalancedPool tls/connect.
All five variants drop the callback. Trusted TLS, HTTP and CONNECT proxy
controls pass without disabling certificate validation. The certificate is
explicitly trusted only by this disposable helper. No production services.
