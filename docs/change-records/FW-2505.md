## Outcome

The public-surface parity gate authorizes a removal, rename, or public
disposition downgrade only through an exact FQCN directive newly added by the
candidate under the canonical Unreleased changelog section. Its base-to-head
map comparison keeps governed concrete final classes visible when a change
deletes both their source and map record.

## Decisions

- Historical releases and pre-existing Unreleased text are evidence, not
  current authority.
- Added, Changed, prose, examples, links, and leaf names never authorize a
  removal.
- A rename replacement must be mapped and loadable in the candidate.
- A missing current map type always fails. Removal authority permits removing
  the map record; it does not permit leaving stale state behind.
- Deprecation authority permits a `public` disposition downgrade while the
  type remains loadable. Actual removal requires the Removed grammar after the
  governed deprecation cycle.
