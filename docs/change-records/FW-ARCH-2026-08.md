## Contract for audit evidence

1. Freeze source and dependency inputs; record subsequent changes separately.
2. Inventory candidates are not defects. Source inspection is not execution.
3. Reproduce defects through real production composition where practical, with
   positive controls and explicit backend/lifecycle scope.
4. Reuse existing issue ownership. Never infer current correctness from a closed
   historical issue or repeat a superseded allegation as a new finding.
5. Recommend keep, remove, replace, consolidate or retain temporarily only with
   consumer/extension/distribution evidence and a migration boundary.
6. Keep unqualified paths visible. Test counts and green CI do not certify the
   entire framework. Agent review is not maintainer approval.
