## Contract and ownership, recorded before qualification

J1-B includes site generation, installation, schema/configuration activation and
required production field-access activation. Successful `install:init` alone
does not complete J1-B. J1-C then requires app-owned Twig rendering through cold,
warm and restarted HTTP; J1-E requires a separate production no-dev installation.
J1-D retains configuration, database, unknown-route and stranger-access refusals.

The entity-field-read boundary contract makes the restricted
`field-access:preflight --format=json` the read-only names-only scanner and sole
artifact producer. Only its explicit `--write-artifact` operation may publish
the canonical checksum-bound result. Qualification must inspect the complete
read-only result and exit status first, retaining the actual framework/package,
classification and entity-schema identities of each installation. A blocker or
scan failure is preserved before any repair. No invented classifications,
hand-written artifact, readiness edits or enforcement changes are authorized.
Normal production boot must keep refusing missing, stale, malformed and
blocker-bearing artifacts. `install:init` must not manufacture this evidence.

The current #3120 mirror remains open and owns prominent consumer production
activation instructions and production HTTP proof. Its current skeleton quick
start omits field-access preflight and incorrectly calls its five phases the
whole lifecycle. Its subsequent-release note additionally requires candidate-
directory configuration authority and HTTP verification before traffic switches;
an existing database/schema alone does not prove activation in a new directory.
This slice revalidates that owner without claiming released-cohort acceptance.

The prior qualification harness also omitted this explicit activation step and
stopped at the expected production refusal. That establishes an omission, not
a lifecycle defect. A fresh exact-base application must now run canonical
preflight before classification is finalized. Any demonstrated runtime repair
requires a recorded contract decision and failing regression first.

producer of the generated PageBundle, whose two FieldTemplate attributes omit

classification contract makes general published content Public. The minimal

first-party published-content recipe explicitly declare the existing Public

all other definitions unchanged. Do not add a scanner waiver, classification
artifact, Framework fallback or installer artifact write. Review this decision
independently; first capture a failing real-console regression that generates

must be captured before another repair. The documentation omission remains
