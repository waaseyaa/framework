Control parsing is exposed before authentication. Yaml is used by configuration
file and sync parsing, and site-contract processing; access to those inputs
depends on the caller. No universal unauthenticated YAML endpoint is claimed.

HttpFoundation because 7.4.19/20 introduced a whitespace-separator regression;

infer consumer protection from a root lock alone.

discriminator for Cache-Control retention, whitespace splitting and excessive

configuration and caller tests; validate/audit both locks; provision a fresh
standalone packaged consumer outside the checkout and run its owning tests.
Run full governed preflight and retain hosted-required results accurately.
PR CI owns full Linux and split-artifact qualification on the final commit.
